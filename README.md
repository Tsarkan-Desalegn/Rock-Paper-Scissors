
# Rock-Paper-Scissors Game ✊🖐️✌️

A simple **Rock-Paper-Scissors** game built with **HTML, CSS, and JavaScript** and with good user interface.  
Players can choose Rock, Paper, or Scissors, and the computer generates a random choice.  
The result (Win, Lose, or Draw) is displayed instantly.

---

## 🎮 Features
- Interactive buttons for Rock, Paper, and Scissors.
- Random computer choice each round.
- Displays both player and computer choices.
- Shows the result with fun emojis and messages.
- Beginner-friendly structure for learning DOM manipulation.


## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click on **Rock ✊**, **Paper 🖐️**, or **Scissors ✌️** to play.
4. The computer will randomly choose, and the result will be shown.


## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for game logic


## 📸 Example Gameplay
- Player clicks **Rock ✊**
- Computer randomly chooses **Scissors ✌️**
- Result: **YOU WIN — Congratulations! 🎉**
